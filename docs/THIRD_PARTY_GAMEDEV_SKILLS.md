# Skills de game development

As orientações abaixo foram instaladas localmente em `.agents/skills/` para o projeto SILÊNCIO a partir de [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills), em 2026-10-29.

Foram selecionadas somente disciplinas úteis ao projeto: `create-game-assets`, `game-feel`, `game-ui-ux`, `level-design`, `performance-optimization`, `game-ai`, `camera-systems`, `physics-tuning`, `input-systems`, `audio-design`, `dialogue-systems` e o gênero `survival-crafting`.

O catálogo upstream informa suporte a Codex e organiza skills por engine, disciplina e gênero. Flutter + Flame não aparece entre as engines listadas; por isso, o projeto não instala nem usa o roteador de engine. As skills portáveis orientam o processo, e toda API/código de exemplo precisa ser adaptado à stack Flutter + Flame existente.

O repositório upstream é distribuído sob Apache-2.0. Os avisos e a licença correspondentes estão em `../.agents/skills/LICENSE.awesome-gamedev-agent-skills` e `../.agents/skills/NOTICE.awesome-gamedev-agent-skills`.
